# 📋 Mini Form Builder

A dynamic, web-based form builder application built with **HTML, CSS, JavaScript, and Firebase Firestore** (Modular SDK v13.0.0). Inspired by Google Forms, this tool allows creators to dynamically build multi-question forms, customize themes, and analyze responses in real-time.

## ✨ Features
- **Dynamic Question Builder:** Add multiple short-answer or multiple-choice questions on the fly.
- **Theme Customization:** Choose between a clean **Light Mode** or sleek **Dark Mode** when publishing.
- **Duplicate Prevention:** Automatically blocks duplicate submissions from the same email or phone number.
- **Admin Dashboard:** Real-time responses dashboard mapping answers question-by-question.
- **Fully Responsive:** Optimized for both desktop and mobile viewports.

## 🚀 Tech Stack
- Frontend: HTML5, CSS3, Vanilla JavaScript
- Backend & Database: Firebase Firestore
- Hosting: GitHub Pages / Netlify
